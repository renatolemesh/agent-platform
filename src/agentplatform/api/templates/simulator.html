Como calibrar

  1. Converse aqui com a versão ativa e anote o que não ficou bom.
  2. Em Configuração, ajuste o YAML (persona, diretrizes, perguntas, limites) e proponha uma versão. Ela fica como rascunho.
  3. Volte aqui, escolha o rascunho no seletor e use Comparar com outra versão para reexecutar a mesma conversa.
  4. Ficou melhor? Outra pessoa aprova o rascunho em Configuração (de uma vez ou como canário).
